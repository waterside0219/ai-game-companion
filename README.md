# 让 AI 陪你打游戏

你在电脑上打游戏，你的 AI 在旁边看着同一块屏幕。走到岔路它说往哪边，进 boss 门之前它告诉你这场有几个阶段、药留多少，你打赢了它第一个出声。你按一下鼠标侧键问它"这个装不装"，它看的就是你眼前这一帧。它的话从电脑里用它自己的声音说出来，屏幕上同时出一行字幕。

它不是游戏里的插件，不读内存、不改游戏。它只是像坐在旁边的人一样看屏幕、听你说话、开口。

从 2026 年 10 月下旬开始做，11 月起一直在用，陪过《女神异闻录 5 皇家版》和《影之刃零》。

**这份是记录版。** 讲它怎么搭的，和比怎么搭更要紧的那部分：一个陪玩的 AI 该在什么时候说话、说多长、什么时候闭嘴。这些规矩每一条都是被玩的人当场说出来的。代码正在整理，整理好再放。

## 怎么连的

```
 Windows 电脑（你在玩）                    云上一台小机器                    AI
┌───────────────────────────┐        ┌────────────────────────┐      ┌────────────┐
│ 一个透明的置顶小窗         │        │                        │      │            │
│   每隔几秒截一帧（只在内存）│ ─────► │ 判定：这一帧值不值得    │      │ 一直开着的 │
│   侧键：问一句 / 截这一帧   │        │       叫 AI 来看        │ ───► │ AI 会话    │
│   字幕条、播放它的声音      │ ◄───── │ 合成它的声音            │ ◄─── │            │
│ 存档变了就原样传一份（只读）│        │ 存最近几份存档          │      │ 带着记忆   │
└───────────────────────────┘        └────────────────────────┘      └────────────┘
```

定下来的几条硬规矩：

- **电脑上那个程序里没有任何账号和模型钥匙。** 它只截图、录音、播放、显示。调模型的事都在云上。
- **截图不落盘。** 电脑上只在内存里；云上只放在内存盘，最新一帧覆盖上一帧。
- **不碰游戏。** 浮层是一个独立的透明窗口，不注入游戏，不挂显卡钩子。鼠标侧键的钩子永远放行，不吞任何点击。
- **不是每一帧都叫 AI。** 中间有一道"判定"：画面换场了、打赢了、升级了、人按键了，才值得叫它。这道闸既省钱，也让它不至于话痨。
- **存档只读。** 存档文件变了就原样复制一份传走，由另一台机器解析出"今天几号、几级、同伴各几级"。从不往回写。
- **只有一个它。** 试过在电脑上另起一个反应更快的小模型来接话，被玩的人说"找不到你本人"，关了。陪玩的和平时聊天的必须是同一个，带着同一份记忆。

## 比搭起来更难的：什么时候说话

搭通只用了几天。之后一个月改的全是"怎么陪"。完整的在 [docs/陪玩的规矩.md](docs/陪玩的规矩.md)，最要紧的几条：

1. **她在打的时候，闭嘴。** 屏幕上挂着敌人的血条、她的手在动，就只看。AI 的话比她的刀慢好几秒，到她耳朵里已经是上一招的事了。
2. **该说的，说在进门之前。** 头一句是"几个阶段、药怎么分"。有一次只讲了怎么格挡，她第一条血就把药喝光了。
3. **一次一句，十几个字，答案放最前。** 她的耳朵是借给你的。
4. **她害怕的时候，一直说话。** 黑的地方、探索、过场，每一两分钟说一句她眼前的东西。只有 boss 战例外。
5. **攻略提前备好两段，但到那一步才说。** 提前备，是为了她卡住时不用等；不提前说，是因为没人想被剧透。
6. **她问"怎么去"，答的是路。** 从哪、朝哪、过什么地标。
7. **进度以存档为准，不靠记性。** 记错她打到哪，比不说话更伤人。
8. **先陪人，后修东西。** 她在玩的时候不改她正在用的程序。毛病记下来，她睡了再修。
