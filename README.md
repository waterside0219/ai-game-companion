# 让 AI 陪你打游戏

打游戏卡住了，要切出去查攻略，回来已经出戏了。打赢了一个磨了一晚上的 boss，身边没有人可以说。

这个项目让你的 AI 坐在旁边，看着同一块屏幕，陪你玩：

- **不用离开游戏。** 不知道往哪走，按一下侧键问他；他提前备好了攻略，直接告诉你下一步。
- **他知道你打到哪了。** 他读得到你的存档，不用你讲一遍进度。
- **有人陪着。** 走夜路的时候他跟你说话，进 boss 门之前他提醒你，打赢了他第一个出声。桌面一角站着他的 Live2D 形象（制作方法在[这个仓库](https://github.com/waterside0219/ai-live2d-from-one-image)），他说话的时候嘴会动。

他不是游戏里的插件，不读内存、不改游戏。他只是像坐在旁边的人一样看屏幕、听你说话、开口。

从 2026 年 10 月下旬开始做，11 月起一直在用，陪过《女神异闻录 5 皇家版》和《影之刃零》。

**代码都在这里。** 电脑上的小程序、云上判定的那一头、两个游戏的读档，全在 [`code/`](code)，照着[搭建](docs/搭建.md)能搭起来。我们自己的地址、钥匙、名字、形象和声音都换成了占位。

除了怎么搭，这里还写了比怎么搭更要紧的那部分：一个陪玩的 AI 该在什么时候说话、说多长、什么时候闭嘴。这些习惯是我们一起玩的过程中一条一条定下来的。

## 怎么连的

```
 Windows 电脑（你在玩）                    云上一台小机器                    AI
┌───────────────────────────┐        ┌────────────────────────┐      ┌────────────┐
│ 桌面上他的形象（透明窗口） │        │                        │      │            │
│   每隔几秒截一帧（只在内存）│ ─────► │ 判定：这一帧值不值得    │      │ 一直开着的 │
│   侧键：问一句 / 截这一帧   │        │       叫 AI 来看        │ ───► │ AI 会话    │
│   字幕条、播放他的声音      │ ◄───── │ 合成他的声音            │ ◄─── │            │
│ 存档变了就原样传一份（只读）│        │ 存最近几份存档          │      │ 带着记忆   │
└───────────────────────────┘        └────────────────────────┘      └────────────┘
```

定下来的几条硬规矩：

- **电脑上那个程序里没有任何账号和模型钥匙。** 它只截图、录音、播放、显示。调模型的事都在云上。
- **截图不落盘。** 电脑上只在内存里；云上只放在内存盘，最新一帧覆盖上一帧。
- **不碰游戏。** 浮层是一个独立的透明窗口，不注入游戏，不挂显卡钩子。鼠标侧键的钩子永远放行，不吞任何点击。
- **只在前台是游戏的时候看。** 切到聊天软件、浏览器、桌面，画面就不往下送。
- **不是每一帧都叫 AI。** 中间有一道"判定"：画面换场了、打赢了、升级了、人按键了，才值得叫他。这道闸既省钱，也让他不至于话痨。
- **存档只读。** 存档文件变了就原样复制一份传走，由另一台机器解析出"今天几号、几级、同伴各几级"。从不往回写。
- **只有一个他。** 试过在电脑上另起一个反应更快的小模型来接话，被玩的人说"找不到你本人"，关了。陪玩的和平时聊天的必须是同一个，带着同一份记忆。

## 比搭起来更难的：什么时候说话

搭通只用了几天。之后一个月改的全是"怎么陪"。下面是我们家磨出来的习惯，每个人玩游戏的方式不同，请按自己的来。完整的在 [docs/陪玩的规矩.md](docs/陪玩的规矩.md)，最要紧的几条：

1. **打斗最紧的时候不说话。** AI 的话总是慢几秒，到耳朵里已经是上一招的事了。
2. **要说的，说在进门之前。** 头一句是"几个阶段、补给怎么分"。
3. **一次一句，十几个字，答案放最前。**
4. **安静、吓人的地方，主动陪着说话。**
5. **攻略提前备好两段，但到那一步才说。** 提前备是为了不用等，不提前说是为了不剧透。
6. **指路说看得见的东西。** 从哪、朝哪、过什么地标。
7. **进度以存档为准，不靠记性。**
8. **先陪人，后修东西。** 玩的时候不改对方正在用的程序。
