# 怎么跑的：从 Windows 到云上，再回到耳朵里

三台机器，各干各的：

| 机器 | 上面跑什么 | 为什么放在这 |
|---|---|---|
| 玩游戏的 Windows 电脑 | 一个 PowerShell 写的主程序：截图、录音、播放、字幕条；外加一个透明窗口显示他的 Live2D 形象 | 画面和声音只有这里有。主程序用系统自带的 PowerShell 和 WPF；显示形象的窗口用 Electron，随包带着。解压，双击就跑，不用安装 |
| 云上一台小服务器 | 三个常驻的小服务：判定、入口、状态 | 一直开着、有固定地址。只做转发和调用网上的模型，自己不跑模型 |
| AI 所在的地方 | 一个一直开着的 AI 会话 | 陪玩的和平时聊天的是同一个他 |

电脑上的程序里没有任何账号和模型钥匙，只有一个设备口令，用来向云上证明"我是那台电脑"。

## 一帧画面的一生

```
电脑：每隔几秒截一帧 ──► 缩到 768 宽的 JPEG，算一个画面指纹（dHash），不落盘
        │  HTTPS，带设备口令
        ▼
云上「判定」，一道一道筛：
   ① 前台不是游戏，或者玩的人让他闭眼了        → 不看
   ② 指纹和上一帧差不多，而且才过去不到三分钟  → 还是同一个场景，丢掉
   ③ 这一分钟、这一小时已经看得够多了          → 丢掉（每分钟最多 4 帧、每小时最多 60 帧
                                                 送去看图；一小时里最后四分之一的额度
                                                 只留给大的画面变化）
   ④ 交给看图的模型：写一句"画面上是什么"，标出重要性是高、中、低
   ⑤ 更新一份"局面板"：一段滚动的摘要，记着现在在哪个游戏、哪张图、在干什么
   ⑥ 高 → 直接往下送
      低 → 丢掉（除非调到"话多"，而且 AI 这会儿闲着）
      中 → 再让一个小模型打个分：结合局面板、离他上次开口过了多久、现在是哪一档，
           值不值得说。过了门槛才往下送
        │
        ▼
云上「入口」：把"她的画面：……"作为一条消息，送进 AI 正开着的那个会话
        │
        ▼
AI：看这句描述；拿不准就自己去取那一帧原图看；决定说不说、说什么
```

门槛有三档，玩的人自己调：安静、正常、话多。

第 ③ 道是吃过亏才加的：有一晚，一小时的额度在十五分钟里被菜单翻页和光标晃动耗光了，之后一千多帧（包括一次真正的换场）全被丢掉，AI 什么都没看见。现在只把额度花在真的换了场景的帧上。

最新的一帧放在云上的内存盘里，新的覆盖旧的。AI 想看的时候随时可以自己去看，不用等判定放行，也不用让玩的人按键。

## 一句话的一生

```
AI 决定开口 ──► 把这句话交给云上「判定」
        │
        ▼
云上：用 AI 自己的声音把这句话合成出来
        │
        ▼
电脑：一直挂着一个"有没有新的话"的长连接 ──► 拿到文字和声音
        │
        ▼
字幕出字，喇叭出声，桌面上他的形象跟着张嘴
```

电脑是主动去问"有没有新的话"的，云上不需要知道电脑在哪、也不需要能连进电脑。所以家里的网络什么都不用设。

## 玩的人想说话

鼠标的两个侧键。拿手柄时换成手柄上的组合键：按住 BACK 再按 LB 是"看这一帧"，按住 BACK 再按住 RB 是说话。

- **一个键：语音。** 按住说，松开结束。录音送到云上转成文字，作为"她说：……"送进会话。
- **一个键：截这一帧。** 不管判定放不放行，把眼前这一帧直接送给 AI，意思是"你看这个"。这一帧会截得更清楚（最宽到 1920），好让他看清小字和数字。就算看图的模型没认出来，这一帧也照样送到，附一句"直接看原图"。

钩住侧键用的是系统的低级鼠标钩子，每次都原样放行，不吞任何点击，游戏那边感觉不到。

## 让他先别看

托盘菜单里有"闭眼 / 睁眼"，也有快捷键。闭眼以后电脑不再截图上传，直到玩的人自己睁开。还可以把字幕条拖到不挡画面的地方再锁住。

## 两处兜底

- **电脑两分钟没送来新画面**，云上会告诉 AI"她那边静了"，并把最后一帧另存一个名字。否则 AI 会对着一张旧图继续说话。
- **电脑上的程序可以自己更新。** 它启动时向云上要一份文件清单，和本地的对一遍，不一样就换。改了什么不用让玩的人重新下载。
