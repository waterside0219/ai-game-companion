# 照着搭起来

三处要动手：云上一台小机器、玩游戏的 Windows 电脑、AI 那头。代码在 [`code/`](../code)，每一块干什么见 [code/README.md](../code/README.md)。

## 0. 先备齐

- **云上一台 Linux 小机器**，Python 3.11 以上（只用标准库），有 `flock`。AI 的会话也跑在这台机器的 tmux 里（入口要往它的窗格里敲字）。
- **一个电脑能连到的地址**，转到这台机器的 127.0.0.1:8833。我们用的是 Cloudflare Tunnel。
- **钥匙**：OpenRouter（看图、判断该不该开口、听写备用）、MiniMax（合成他的声音，先做好一个音色拿到 voice_id）、ElevenLabs（听写，可选）。
- **一台 Windows 电脑**，自带的 PowerShell 5.1 就行。

## 1. 云上

```
cd code
mkdir -m 700 -p .private
cp judge/config.example.toml .private/config.toml
python3 -c "import secrets; print(secrets.token_urlsafe(32))"   # 这串当设备口令
```

改 `.private/config.toml`：

- `device_token`：上面那串，电脑上要填同一串
- `minimax_key_path`：MiniMax 钥匙文件的路径（比如 `.private/minimax-key`），`voice_id`：你的音色
- `direct_tmpfs = "/dev/shm/desk"`：人按键要他看的那一帧放在这里（内存盘，不落硬盘），AI 能直接读原图
- `transcribe_enabled = true`：按住说话要转成字才开

再建 `.private/providers.env`（权限 600）：

```
DESK_PROVIDERS=real
OPENROUTER_API_KEY=你的钥匙
DESK_KEYTERMS=你们常说的名字,游戏里的角色名
```

ElevenLabs 的钥匙放 `.private/elevenlabs-stt-key`（不放就只用 OpenRouter 听写）。不写 `DESK_PROVIDERS=real` 时一律走假的，不花钱，适合先把链路跑通。

**三个常驻进程**，crontab 里加：

```
* * * * * DESK_TMUX_TARGET=ai /bin/bash /path/to/code/deploy/run-desk.sh
* * * * * DESK_TMUX_TARGET=ai /bin/bash /path/to/code/deploy/run-entry.sh
* * * * * DESK_TMUX_TARGET=ai /bin/bash /path/to/code/deploy/run-status.sh
* * * * * DESK_TMUX_TARGET=ai /usr/bin/python3 /path/to/code/entry/desk_quiet.py
```

`DESK_TMUX_TARGET` 是 AI 会话所在的 tmux 窗格（`会话名:窗口.窗格`）。脚本自己带 `flock`，每分钟拉一次只会有一个在跑。

**让入口知道 AI 忙不忙。** 入口只在 AI 闲着的时候敲字：它看窗格最后 15 行有没有"正在跑"的转圈，再看 `.private/work-state.json`。这个文件由 AI 那头写：开始干活写 `{"state": "work", "at": 当前时间戳}`，停下写 `{"state": "idle", "at": …}`。Claude Code 可以用 hooks 在 `UserPromptSubmit` 和 `Stop` 时各写一次。

**确认：** `curl -s 127.0.0.1:8833/v1/say` 回 401（没带口令）。`python3 -m unittest discover -s tests` 全过。

## 2. Windows

把 `code/client/` 整个拷到电脑上，再放两样仓库里没有的：

- **Electron**：下载 Windows x64 版的 Electron 压缩包，解到 `client/electron/`，让 `client/electron/electron.exe` 存在。
- **Live2D**（他的形象）：`client/live2d/vendor/live2dcubismcore.min.js`（Live2D 官网按条款下载）、`client/live2d/vendor/cubism-framework.js`（从 CubismWebFramework 编出来），模型放进 `client/live2d/runtime/`，入口文件名改成 `model.model3.json`。模型怎么从一张图做出来，见 [ai-live2d-from-one-image](https://github.com/waterside0219/ai-live2d-from-one-image)。

第一次双击 `start.bat`，它会在 `%APPDATA%\desk-companion\` 建 `config.json` 并打开让你填：

- `base_url`：上面那个地址
- `device_token`：跟云上同一串
- `games`：额外算作"游戏"的程序名。Steam、Epic、WeGame 装的游戏不用写，自动认
- `side_button`、`voice_button`：鼠标侧键哪个是"截这一帧给他看"、哪个是"按住说话"
- `talk_level`：quiet / normal / chatty

**确认：** 右下角出现他的形象；进游戏按一下侧键，AI 的会话里会出现一条 `[电脑陪玩 …]`；AI 跑 `python3 entry/desk_say.py <event_id> "一句话"`，电脑上出字幕、出声音。

以后改了客户端文件，放到云上的 `code/client/` 里就行：电脑每次启动会对照 sha256 拉新的。

## 3. 读档（可选）

电脑上的程序会自己找《女神异闻录 5 皇家版》和《影之刃零》的存档，游戏一写就原样传到云上。怎么读见 [saves/README.md](../code/saves/README.md)。加一个新游戏：在 `desk-overlay.ps1` 里加一个存档路径，再写一个解析。

## 4. 跟 AI 说清楚规矩

在 AI 的长期说明里写上：以 `[电脑陪玩 …]` 开头的是游戏画面报来的事，不是人在聊天；回话只用 `desk_say.py`；打斗最紧的时候不说话。我们家磨出来的习惯在 [陪玩的规矩](陪玩的规矩.md)，可以照着改成你们的。
